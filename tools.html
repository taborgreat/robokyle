What we’ve shipped

Small tools, one honest problem each.

Every tool below solves one thing well, works with a keyboard, plays nicely with screen readers, and is free to use, fork, and rebuild. If a tool ever stops meeting that bar, we take it off this page until it does.

Caption Remixer

Paste any VTT or SRT and get a cleaner, plain-language version — speaker labels, sound cues, and line breaks tuned for readability.

Status: shipped · MIT

Contrast Checker

Drop two colours in, get WCAG 2.2 contrast scores at every text size, plus the nearest passing pair if yours misses.

Status: shipped · MIT

Keyboard File Picker

A drop-in replacement for the browser file dialog that’s fully keyboard driven, screen-reader labelled, and works without a mouse ever touching the page.

Status: shipped · MIT

Reading Ruler

A tiny bookmarklet that overlays a movable highlight bar on any page — helpful for dyslexia, tracking, and long-form focus.

Status: shipped · MIT

Focus Ring Auditor

Scans a page and flags every interactive element whose focus indicator falls below the 3:1 contrast bar. One-click browser extension.

Status: shipped · MIT

Plain-Language Linter

Flags jargon, passive voice, and reading-grade drift as you type. Ships as a CLI and a VS Code extension.

Status: beta · MIT

Alt-Text Helper

Paste an image URL, get three alt-text drafts at different lengths — you pick the one that fits. Runs on-device where possible.

Status: beta · MIT

Motion Guard

A pre-flight check that catches animations, autoplaying video, and parallax that ignore prefers-reduced-motion.

Status: beta · MIT

More on the way

Switch-input remapper, low-vision zoom overlay, and a screen-reader-first form builder are all in co-design right now.

Status: in co-design

How to use these

Free, MIT, no strings.

Every tool is on GitHub. Clone it, embed it, rebrand it, ship it inside your own product — we just ask that whatever you build with it stays accessible to the people the tool was built for.

  • No account, no email capture, no telemetry by default.
  • Runs on-device wherever it’s technically possible.
  • Documented in plain language, not spec-speak.
  • Every release is tested with a screen reader before it ships.
