Contribute

Write a guide with us.

Every guide starts from the same template, uses the same voice rules, and gets a plain-language review from a disabled reader before it ships. If you’ve got a walkthrough you wish existed, we’ll help you get it written.

  • Start from the guide template — skeleton and style rules already baked in.
  • Open a pull request; we’ll pair on the edit rounds.
  • Contributors get credit on the guide and, if you want it, on the About page.
